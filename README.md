# Kiago - React Native Base Project

Este es un proyecto base de **React Native** creado con **Expo**, configurado con **TypeScript**, **Yarn** y diseñado con una estética **Premium**.

## 🚀 Características

- **Expo Router:** Navegación basada en archivos (Tab bar pre-configurado).
- **TypeScript:** Tipado estricto para un desarrollo seguro.
- **Estética Premium:** Paleta de colores moderna (Slate/Indigo), Glassmorphism y animaciones fluidas con `react-native-reanimated`.
- **Lucide Icons:** Iconos vectoriales consistentes y modernos.
- **Gradients:** Uso de `expo-linear-gradient` para fondos dinámicos.

## 🛠️ Requisitos previos

- Node.js (v18 o superior)
- Yarn
- Expo Go (en tu dispositivo móvil para pruebas rápidas)

## 📦 Instalación

1. Clona el repositorio (si aplica).
2. Instala las dependencias:
   ```bash
   yarn install
   ```

## 🏃 Cómo ejecutar

Inicia el servidor de desarrollo de Expo:

```bash
yarn start
```

Desde el menú de Expo, puedes elegir:
- `i` para abrir en el simulador de **iOS**.
- `a` para abrir en el emulador de **Android**.
- `w` para abrir en el navegador (**Web**).

## 📂 Estructura del Proyecto

- `app/`: Contiene las rutas y pantallas (Expo Router).
- `components/`: Componentes UI reutilizables.
- `constants/`: Tokens de diseño (Colores, Espaciado).
- `assets/`: Imágenes y fuentes.
